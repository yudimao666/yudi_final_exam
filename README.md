# yudi_final_exam

This repository contains a Jupyter notebook that:
Loads GHCN-D daily temperature data for Plant City (USC00087205).
Computes mean monthly frost (≤32°F) and freeze (≤28°F) risk for Oct–Jan during 1991–2020.
Merges results with NOAA CPC ENSO indices and calculates correlations to identify which ENSO region best relates to freeze events.
